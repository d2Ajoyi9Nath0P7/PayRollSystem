# Payroll Management System (Java)

## Project Overview
This is a Java-based Payroll Management System designed to manage employee records and salary calculations for both Full-Time and Part-Time employees. The system uses Object-Oriented Programming principles, demonstrating concepts such as abstraction, inheritance, and polymorphism.

## Features
- Add and remove employees dynamically.
- Support for Full-Time employees with fixed monthly salary.
- Support for Part-Time employees with salary based on hours worked and hourly rate.
- Display employee details including calculated salary.
- Utilizes abstract classes and method overriding.
- Manages employee data using Java's ArrayList for dynamic storage.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework (ArrayList)

## Project Structure
- `Employee` (abstract class): Base class with common attributes and abstract salary calculation method.
- `FullTimeEmployee`: Subclass implementing salary calculation based on fixed monthly salary.
- `PartTimeEmployee`: Subclass implementing salary calculation based on hours worked and hourly rate.
- `payrollSystem`: Manages the list of employees with add, remove, and display functionalities.
- `Main`: Entry point demonstrating usage of the payroll system.

## How to Run
1. Compile all Java files in the `Payroll` package.
2. Run the `Main` class.
3. The system will demonstrate adding employees, displaying them, removing an employee, and displaying the updated list.
